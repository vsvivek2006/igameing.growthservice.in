# iGaming GrowthService — Antigravity Master Build Prompt

## Research-grounded implementation brief

### Business positioning
GrowthService is being positioned as a specialist B2B digital-growth agency for high-competition, policy-sensitive verticals. The service model spans SEO, SEO-first website development, technical/on-page/off-page SEO, content strategy, backlinks/digital PR, CRO, analytics/attribution, and paid acquisition where a client, destination, jurisdiction, licence/certification status, and advertising platform permit it.

The target vertical set includes:
- iGaming / gaming platforms
- Casino and gambling-related brands
- Cricket / fantasy / sports-gaming platforms
- Yono-style gaming and related high-competition search markets
- Colour prediction and colour-trading businesses
- Stock-market, trading and other financial/digital investment businesses
- Escort/adult-services businesses, handled strictly as a B2B marketing vertical and without explicit sexual content

### Existing project findings
The main GrowthService repository is already architected as a Vite + React + TypeScript application with a centralized data/routing/SEO architecture. The documented system uses a Single Source of Truth pattern for business data, services, locations, routes and SEO logic. The main repository also has validation scripts for routing, sitemap, SEO, data integrity and centralization.

The new repository `vsvivek2006/igameing.growthservice.in` is already a React 18 + Vite + TypeScript + Tailwind application with React Router, React Helmet and Lucide icons. It contains a 50-indexable-page registry, dynamic service/industry/service×industry/guide routing, sitemap generation, SEO validation, SEO monitoring, smoke tests, launch checklists and related documentation. Do not throw this architecture away. Inspect it first and improve it in-place.

The current homepage in the new repository is already much more sophisticated than a basic landing page: dark premium hero, specialist positioning, SEO-first website development, technical SEO, paid acquisition, CRO, compliance-aware strategy, vertical-specific intelligence, methodology, resources, process and FAQs. Preserve good parts and evolve them rather than rebuilding blindly.

### Important technical/SEO research conclusion
The site must NOT pursue a large page count by mass-producing near-identical city, keyword or industry pages. Google explicitly warns against doorway abuse and scaled content abuse. A 100–200+ page target is acceptable only when every page has a distinct user purpose, original information, meaningful differentiation, useful internal links and indexation quality controls.

### Paid-media research conclusion
Gambling/games advertising is policy- and jurisdiction-sensitive. Google currently requires certification for gambling/gambling-promoting advertising where applicable, valid local licensing for targeted regions where required, and destination compliance. Google has also reiterated that gambling certification requires the relevant business-controlled domain rather than a generic/free hosting subdomain. Financial-services advertising can require jurisdiction-specific verification and licensing/exemption information, including in India. Therefore the website must describe paid-media services as compliance-aware, jurisdiction-dependent and subject to platform eligibility; never promise policy bypasses.
